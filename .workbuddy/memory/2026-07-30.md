# 2026-07-30 工作日志

## 修复：顶栏「高级」按钮点击导致编辑器崩溃（Bug）
- 现象：点击顶栏「高级」(tw.menuBar.advanced) 打开设置弹窗时，整个编辑器崩溃（白屏）。
- 根因：上一轮在 `src/components/tw-settings-modal/settings-modal.jsx` 新增的 `ApiKeySetting` 组件内部用 `this.props.intl.formatMessage(...)` 取 placeholder，但该 class 组件**未用 `injectIntl` 包裹**，且父组件渲染 `<ApiKeySetting />` 时也没传 `intl`，导致 `this.props.intl` 为 `undefined`，渲染即抛 `Cannot read properties of undefined (reading 'formatMessage')`。
- 同文件内 `Setting = injectIntl(UnwrappedSetting)` 是正确范式。
- 修复：将 `const ApiKeySetting = class extends React.Component {` 改为 `const ApiKeySetting = injectIntl(class extends React.Component {`，并把结尾 `};` 改为 `});`，使其被 injectIntl 包裹、内部能取到 `intl`。
- 易退回：✅；危害🟢低。已确认 `editor~embed~fullscreen~player.js` 重新编译无语法错误（curl 200、无 SyntaxError 标记）。
- 注意：本崩溃是我上一轮新增「TwT 服务 / AI 审核 API Key」设置项引入的，非项目原有 bug。
