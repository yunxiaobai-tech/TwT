# 2026-07-29

## AI 审核 API Key 改为「自填」
- 需求：把反馈区 AI 审核（Pollinations）从默认匿名改为用户自填 Key。
- 根因：原 `src/lib/tw-feedback-ai.js` 经 `/tw-ai-proxy` 调 Pollinations 不带 token，匿名额度会撞 402。
- 改动（纯增量、向后兼容，无 key 时仍匿名）：
  - `src/lib/tw-feedback-ai.js`：新增 `AI_API_KEY_STORAGE='twt_ai_api_key'` 与 `getApiKey()`；`attemptOnce` 在存在 key 时给请求头加 `Authorization: Bearer <key>`。
  - `src/components/tw-settings-modal/settings-modal.jsx`：新增 `ApiKeySetting` 类组件 + 在面板末尾加「TwT 服务」小节，密码输入框写入/清除 `localStorage.twt_ai_api_key`（含 placeholder、清除按钮、help 文案，全部 FormattedMessage）。
  - `src/components/tw-settings-modal/settings-modal.css`：`.apiKeyRow` / `.apiKeyInput`（用已存在变量 `$input-background` / `$ui-tertiary` / `$text-primary` / `$ui-primary`）。
  - `changelog-data.js`：新增 `v2026.7.29` 一条 `new` 记录。
- 易退回：✅（删输入控件 + 3 行 header 逻辑即可）；危害🟢低（key 仅存本机、只发往 Pollinations 鉴权）。
- 代理：webpack `onProxyReq` 只删 origin/referer，会透传 Authorization 头，故 dev 下自填 key 可用。
- 验证：`editor~embed~fullscreen~player.js` 含 twt_ai_api_key / getApiKey / Bearer / aiApiKey / 中文标签 / TwT 服务。dev server 已重编译。
- 注：key 走 localStorage（非 redux），未接「保存到项目」。生产静态构建无 `/tw-ai-proxy` 代理，此审核仅 dev/有后端代理时可用（与原有匿名行为一致）。
- 实测（2026-07-29）：用户给的 key 经代理带 `Authorization` 头 → Pollinations 返回 402 但明确是 "authenticated users" 且 "this key has 0.0000 pollen"，说明**自填 key 链路正确、代理透传 OK**，402 是 **key 的 pollen 额度为 0 的账单问题**，非代码问题；匿名请求现在也 402（legacy text API 正在废弃）。结论：代码已可用，待用户给 key 充值 pollen 后即可生效。
