- **教训**：React class 组件的事件处理器必须保证 `this` 绑定；无充分测试不要盲目改成类方法引用

## TwT 忘记密码按钮无响应修复
- **问题**：点击"忘记密码"按钮无任何反应
- **原因**：性能优化时将 `onClick={() => this.startForgotPassword()}` 改为 `onClick={this.startForgotPassword}`，但未绑定 `this`，导致方法内 `this.setState` 报错
- **修复**：恢复为内联箭头函数形式 `onClick={() => this.startForgotPassword()}`
- **教训**：无参数的 onClick 可提取为类方法（需绑定 this），但简单调用场景建议保留内联箭头避免绑定问题
- **验证**：括号平衡检查通过 ✅

## TwT 忘记密码 Turnstile 修复
- **问题**：注册后点"忘记密码"，人机验证不显示
- **原因**：注册时 Turnstile 已渲染（`_turnstileRendered = true`），忘记密码时 `loadTurnstile()` 检测到已渲染直接跳过
- **修复**：在 `startForgotPassword()` 中先调用 `removeTurnstile()` 清除旧状态，再加载新 Turnstile
- **文件**：`src/components/tw-login-modal/login-modal.jsx`
- **验证**：括号平衡检查通过 ✅
